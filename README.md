# AutoClicker — утилита автоматизации кликов на Python

Простой автокликер с графическим интерфейсом для автоматизации рутинных действий в интерфейсах. Подходит для тестирования UI, демо-презентаций и автоматизации повторяющихся задач.

> ⚠️ **Важно:** Не используйте утилиту в онлайн-играх и сервисах с античитом — это нарушает правила большинства платформ и может привести к блокировке аккаунта.

---

## Возможности

- Точная настройка интервала между кликами (в секундах).
- Выбор кнопки мыши (левая/правая/средняя).
- Режим работы: одиночный клик или циклическая работа до остановки.
- Графический интерфейс на `tkinter` — ничего не нужно настраивать через консоль.
- Сборка в один исполняемый файл (`.exe`) без необходимости установки Python.
- Поддержка кастомной иконки приложения.
